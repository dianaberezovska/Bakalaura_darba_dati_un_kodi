# ARBIMON parauga atbilstības rīka pielietojuma efektivitāte _Conocephalus dorsalis_ (Insecta: Orthoptera) automātiskai klātbūtnes noteikšanai
Angliski - "The effectiveness of ARBIMON pattern matching tool for automatic detection of Conocephalus dorsalis (Insecta: Orthoptera) presence."

Bakalaura darbs
Diāna Berezovska

Šajā repozitorijā ir apkopoti autora bakalaura darba pētījuma dati un to apstrādes materiāli. Šeit ir pieejamas datu tabulas ar audiovizuālajiem datiem, kurās apkopota informācija par visu pārskatīto audioierakstu Conocephalus dorsalis sugas klātbūtni, kā arī tabula ar audiovizuālo datu un paraugu atbilstības rīka rezultātiem. Repozitorijā ir iekļauti arī R kodu skripti, kas tika izmantoti datu sakārtošanai, statistiskajai analīzei un vizualizācijai, tostarp audioierakstu attēlošanai spektrogrammu un oscilogrammu veidā. Papildus ir pieejama pētījumā iegūto attēlu un grafiku mape.
